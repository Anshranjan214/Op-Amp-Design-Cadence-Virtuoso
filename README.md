## 📌 Project Overview

This project focuses on the **design, simulation, and analysis of Operational Amplifier (Op-Amp) circuits** using **Cadence Virtuoso**, a widely used Electronic Design Automation (EDA) platform for analog and mixed-signal integrated circuit design.

The project covers the fundamental stages of analog IC design, including schematic development, circuit simulation, physical layout design, and verification techniques.

It aims to develop a practical understanding of the analog design workflow while exploring circuit performance, simulation accuracy, design optimization, and verification methodologies.

---

## 🎯 Project Objectives

- Understand the fundamental principles of operational amplifier design.
- Develop circuit schematics using Cadence Virtuoso.
- Perform analog circuit simulations using Spectre.
- Analyze DC, AC, and transient circuit responses.
- Understand physical layout development.
- Implement Design Rule Checking (DRC) and Layout Versus Schematic (LVS).
- Explore circuit optimization and simulation efficiency.

## 🔬 Project Workflow

The project follows a standard analog integrated circuit design workflow:

| Step | Design Phase | Description |
|:---:|:---|:---|
| 01 | **Schematic Design** | Create the Op-Amp circuit schematic in Cadence Virtuoso. |
| 02 | **Simulation Setup** | Configure circuit parameters, models, and simulation conditions. |
| 03 | **Circuit Simulation** | Perform DC, AC, transient, and other relevant analyses using Spectre. |
| 04 | **Layout Design** | Develop the physical layout of the circuit. |
| 05 | **DRC Verification** | Check compliance with design rules. |
| 06 | **LVS Verification** | Verify consistency between schematic and layout. |
| 07 | **Performance Analysis** | Evaluate gain, bandwidth, stability, and other circuit characteristics. |
| 08 | **Final Verification** | Validate the design for potential fabrication preparation. |

## 📊 Performance Parameters

The following parameters are relevant to evaluating an operational amplifier:

| Parameter | Description |
|:---|:---|
| **Open-Loop Gain** | Amplification provided without feedback |
| **Gain Bandwidth Product** | Relationship between gain and operating bandwidth |
| **Phase Margin** | Indicator of closed-loop stability |
| **Slew Rate** | Maximum rate of change of output voltage |
| **Input Offset Voltage** | Differential input voltage required for zero output |
| **CMRR** | Common-Mode Rejection Ratio |
| **PSRR** | Power Supply Rejection Ratio |
| **Power Consumption** | Total power consumed by the circuit |

> **Note:** Actual performance values depend on the circuit topology, transistor models, technology node, and simulation results.
